# 🏥 ZELO - Conectando Cidadãos à Saúde Pública

> **Projeto desenvolvido no ecossistema de inovação do Embarque Digital e Porto Digital (Recife).**

## 💡 Sobre o Projeto
O ZELO é uma solução tecnológica (MVP) concebida para resolver um problema estrutural crônico na saúde pública: as filas de madrugada e a falta de visibilidade sobre a disponibilidade de fichas nas Unidades Básicas de Saúde (UBS). 

Em vez de o utente se deslocar fisicamente à UBS sem a garantia de atendimento, a plataforma permite a verificação e o agendamento de forma remota, integrada e inteligente.

## 🚀 O Problema vs. A Solução
- **O Problema:** Deslocações desnecessárias, tempo de espera exaustivo e processos manuais que falham na gestão de fichas diárias.
- **A Solução:** Um fluxo digital que conecta a UBS ao cidadão, transferindo a gestão da fila para a "palma da mão" do utilizador, devolvendo tempo e dignidade à comunidade.

## 🛠️ Tecnologias e Metodologias Utilizadas
- **Prototipação & UI/UX:** Figma Make
- **Linguagens:** Node / React / Next / TypeScript / JavaScript / HTML / CSS 
- **Metodologia:** Mapeamento de Processos, Design Thinking e validação de modelo de negócio (Pitch).
